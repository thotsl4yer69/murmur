# Project Status — MURMUR

**Portfolio class:** Private active R&D / future flagship candidate  
**Maturity:** **Concept + hardware prototype planning**  
**Last portfolio review:** 2026-08-13

MURMUR is a privacy/autonomy-oriented wearable/product R&D program combining garment design, embedded electronics, sensing and a supporting digital/product layer.

## Evidence boundary

Only capabilities demonstrated on actual prototype hardware should be promoted as functional product features. Conceptual privacy/counter-surveillance ideas, lab-only experiments and regulated RF behaviours must remain clearly separated from demonstrated, lawful product capabilities.

## Public-release gate

- working Prototype 01 hardware;
- photographed/filmed evidence;
- verified power/thermal/wearability data;
- clear legal/safety scope for active electronic functions;
- product architecture and BOM tied to the demonstrated build;
- website claims reconciled to tested evidence.

**Portfolio use:** strong future evidence of wearable-electronics/product integration once the physical prototype is demonstrated.
